1. DATASET SOURCES
================================================================================
The project does not consume any public or third-party dataset. No external
employment, demographic, or research dataset was used. It does include one
project-authored reference dataset, classified below as a SECONDARY SOURCE.

- PathPoint Reference Dataset (SECONDARY SOURCE — compiled/synthesized)
  File: docs/PathPoint_Reference_Dataset.xlsx
  Generator: docs/generate_dataset.py (deterministic, fixed random seed 42;
             rerun with `python docs/generate_dataset.py` to reproduce)
  Classification: Secondary source. It is a compiled, schema-aligned sample of
             the data PathPoint stores — derived for the project, not primary
             field-collected data and not obtained from any third party.
  Contents (10 sheets): Read Me (cover/data dictionary), Applicants (40),
             Providers (12), Companies (15), Job Listings, Job Applications,
             Company Applications, Tracked Applications, Work Logs, Interviews,
             and a Lookups sheet of controlled values.
  Alignment: Columns mirror the Mongoose models — User, Company, JobListing,
             JobApplication, CompanyApplication, Application, WorkLog — plus a
             derived Interviews view, so the workbook doubles as a data
             dictionary of the app's domain values.
  Use: demos, testing, documentation, and analytics prototyping for the project.
  Note: All names, companies, emails (example.com), and figures are fictional;
        no real person or organization is represented. Do not present as real
        collected data.

- Synthetic seed data (self-authored, illustrative only)
  File: backend/src/utils/seedData.js
  Contents: fabricated demo accounts (applicants, providers, an administrator),
            companies, job listings, company applications, and work logs used to
            exercise the flows during local development and testing.
  Note: This data is invented for demonstration; it is not sourced from any
        external dataset and is not real personal or business information.

- Placeholder document blob
  File: backend/src/utils/seedData.js (pngDocument, base64 1x1 PNG)
  Use: stands in for an uploaded applicant document during seeding.

- Runtime data store
  Service: MongoDB Atlas (cloud-hosted MongoDB)
  Database name: pathpoint
  Use: all persistent application data (users, companies, jobs, applications,
       work logs, notifications, pins, activity log). The database is created
       and populated by the application at runtime, not imported.

5. APIs & EXTERNAL SERVICES
================================================================================
--- Maps & geolocation (frontend, AddressMap) ---
- OpenStreetMap standard tile servers
    URL: https://{s}.tile.openstreetmap.org/{z}/{x}/{y}.png
    Use: base map tiles rendered via Leaflet / react-leaflet.
    Attribution: "© OpenStreetMap contributors" — https://www.openstreetmap.org/copyright
- Nominatim geocoding API (OpenStreetMap) — https://nominatim.org/release-docs/latest/api/Overview/
  - Forward search:  https://nominatim.openstreetmap.org/search?format=jsonv2&q=...
  - Reverse geocode: https://nominatim.openstreetmap.org/reverse?format=jsonv2&lat=..&lon=..
- Browser Geolocation API (navigator.geolocation)
  https://developer.mozilla.org/en-US/docs/Web/API/Geolocation_API
  Use: "Use my location" and map pin placement.

--- Infrastructure / cloud services ---
- MongoDB Atlas (managed cloud MongoDB database) — https://www.mongodb.com/atlas
  Use: persistent storage for the `pathpoint` database.
- Vercel (hosting & deployment for frontend and backend; serverless functions,
  rewrites/proxy) — https://vercel.com/docs
  Production domains referenced: pathpoint.vercel.app (frontend),
  backend-cyan-eight-57.vercel.app (API).
- SMTP email service (any provider; configured via SMTP_HOST/PORT/USER/PASS/FROM)
  accessed through Nodemailer. Use: login verification codes and password reset.
  SMTP reference: https://nodemailer.com/smtp/

--- Project's own API (internal, not third-party) ---
- PathPoint REST API (Express) — served at /api/* (dev: http://localhost:5000/api,
  health check at /api/health). Specified in frontend/BACKEND_SPECIFICATION.md.

--- Browser platform APIs used by the UI ---
- Web Storage API (localStorage / sessionStorage) — session and settings persistence.
  https://developer.mozilla.org/en-US/docs/Web/API/Web_Storage_API
- Fetch API and the Fetch/Streams interfaces (used by Axios/fetch calls)
  https://developer.mozilla.org/en-US/docs/Web/API/Fetch_API
- Geolocation API (see above).
