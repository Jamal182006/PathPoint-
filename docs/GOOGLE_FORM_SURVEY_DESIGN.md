## SECTION 3: FEATURE VALIDATION — PATHPOINT CONCEPT

*Show this intro text before Q13:*

> **PathPoint Concept:** Imagine a single platform where you can:
> - Discover verified company-backed job listings
> - Apply with one profile, track every application status automatically (Saved → Applied → Interviewing → Offered → Rejected)
> - Store and reuse resumes, cover letters, and documents per application
> - Log work experiences and skills for future applications
> - Get notifications for deadlines, interview schedules, and status changes
> - See company verification status so you know listings are legitimate

## GOOGLE FORMS IMPLEMENTATION TIPS

### Creating the Grid Questions (Q9, Q13)
1. Add question → **Multiple choice grid** (for Q9) or **Checkbox grid** (for Q13)
2. **Rows** = Statements/Features
3. **Columns** = Scale (1–5) with labels
4. Enable **"Require a response in each row"**

### Conditional Logic (Section Branching)
- **Q1 = "No"** → Submit form (screen out)
- **Q11 = "No, never tried"** → Skip Q12
- **Q24 ≠ "Yes"** → Skip Q25

### Response Validation
- Q25: Response validation → Text → Email address
- Q14: Response validation → Select exactly 3 (or "Select at most 3")

### Pre-filled Links for Testing
- Use **⋮ More → Get pre-filled link** to test logic flows
